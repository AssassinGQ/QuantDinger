# Requirements: QuantDinger v2.0 Cross-Sectional Strategy

**Defined:** 2026-04-13
**Core Value:** 从数据获取、因子计算、回测验证到实盘执行的完整量化交易链路，确保回测结果真实可靠。

## v1 Requirements

### Universe 管理

- [x] **UNIV-01**: 系统能从公开网页爬取当前 NQ100 成分股列表并解析为标准 symbol
- [x] **UNIV-02**: 后端 API 缓存成分列表 + APScheduler 定时刷新（可配置周期）
- [x] **UNIV-03**: PostgreSQL 存储历史成分快照，支持 PIT 查询（给定日期返回当时的成分股列表）

### 回测正确性

- [ ] **AUDIT-01**: 退市股历史 K-line 数据保留在面板中，不从回测中删除（幸存者偏差修复）
- [ ] **AUDIT-02**: 信号日 close 排名 → 次日 open 执行（T+1 对齐，消除未来函数）
- [ ] **AUDIT-03**: 停牌/涨跌停处理：调仓日买不到的股票留现金，卖不掉的股票被动持有

### 截面回测引擎

- [ ] **BT-01**: 后端多品种截面回测引擎（接收截面指标代码 + symbol_list + 日期范围，构建面板、执行截面指标、T+1 模拟、返回净值曲线 + 标准指标）

### 内置因子

- [ ] **FACTOR-01**: 后端内置 ≥6 种价量因子（momentum/reversal/volatility/volume/mean-reversion/risk-adjusted），可被截面指标和回测脚本直接调用
- [ ] **FACTOR-02**: 因子标准化工具模块（winsorize / z-score / rank），作为共享服务供指标代码和脚本复用

### NQ100 策略类型

- [ ] **STRAT-01**: NQ100Strategy 继承 CrossSectionalStrategy，symbol_list 动态绑定 PIT universe API（非静态 trading_config）
- [ ] **STRAT-02**: 三种 delisting_policy 模式：immediate（生效日平仓）/ delayed_N_months（延迟 N 月）/ hold_until_signal_exit（指标退出时排除），特殊情况（破产/退市风险）无条件立即平仓

### 回测脚本

- [ ] **SCRIPT-01**: 暴力搜索因子子集组合 × 持仓数网格（支持 ≥793 种组合 × 7 种持仓数）
- [ ] **SCRIPT-02**: 标准指标输出（Sharpe / Calmar / MaxDD / 年化收益 / 胜率 / 总交易月数）
- [ ] **SCRIPT-03**: 断点续传（checkpoint）+ JSONL 逐条结果输出
- [ ] **SCRIPT-04**: Walk-forward 滚动验证（训练窗口 + 测试窗口滑动）

## v2 Requirements

### 高级分析

- **ADV-01**: IC/IR 因子有效性诊断
- **ADV-02**: Fama-MacBeth 回归
- **ADV-03**: 交易成本 + 滑点模型
- **ADV-04**: 容量估算（策略可承载资金上限）

### 实盘集成

- **LIVE-01**: 截面策略 IBKR 自动化执行
- **LIVE-02**: A 股截面策略支持
- **LIVE-03**: 截面策略前端管理 UI

## Out of Scope

| Feature | Reason |
|---------|--------|
| 截面策略前端 UI | v2.0 仅后端 + 脚本，前端 v3 |
| A 股截面策略 | v2.0 仅 NQ100，规则/数据源不同 |
| 实盘截面交易自动化 | v2.0 仅回测验证 |
| 全局 sector-neutral 优化 | 需要可靠行业分类数据，v3 |
| 日频调仓 | 成本/噪声主导，先做月频/周频 |
| Long-Short 组合 | 现有截面策略已支持 long_ratio，不需额外开发 |
