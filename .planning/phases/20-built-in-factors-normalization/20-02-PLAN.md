  <action>
    实现 `core.py`：
    - `mom(close, window)`：固定为 `close.pct_change(window)`（即 `P_t/P_{t-window}-1`）。
    - `mom_skip(close, window, skip)`：固定为 `close.pct_change(window) - close.pct_change(skip)`；在 v1 取 `window=252`, `skip=21`。
    - `reversal(close, window)`：固定为 `-close.pct_change(window)`，并在测试中断言与 `mom` 同窗符号相反。
    - `volatility(close, window, annualize=True)`：固定为 `close.pct_change().rolling(window).std(ddof=1)`，年化乘 `sqrt(252)`。
    - `sharpe(close, window, annualize=True, ddof=1)`：超额收益可为 0 均值；std=0 → NaN。
    - `sortino(close, window, annualize=True, ddof=1)`：下行波动固定为 `downside_sq=(r.clip(upper=0.0)**2).rolling(window).mean()`，`downside_std=sqrt(downside_sq)`；下行 std=0 → NaN。

    实现 `factor_defs.py`：
    - `FactorSpec`（frozen dataclass）：`name`, `func`, `direction`, `kwargs`, `category`。
    - `get_builtin_factor_specs() -> dict[str, FactorSpec]`：键为 CONTEXT v1 全集合。
    - `compute_factor_by_name(name, close, volume)`：`volume` 可为空序列（当前 v1 可不用 volume，但签名保留扩展）；若 `volume is None`，内部补齐与 `close.index` 对齐的占位 `Series`，禁止因此抛错。
    - 别名：若脚本有旧名，仅 `factor_defs` 内 deprecated 映射 optional。

    更新 `__init__.py` 导出 registry + core 公共符号。
  </action>
