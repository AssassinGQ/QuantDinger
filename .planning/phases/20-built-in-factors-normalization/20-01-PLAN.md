    - `NormalizeConfig` dataclass（frozen）：字段含 `winsor_lower`, `winsor_upper`, `rank_ties`, `nan_policy`, `enable_zscore`, `zscore_ddof`，默认值与 CONTEXT/RESEARCH 一致。
    - `load_normalize_config_from_env(env=None)`：读取 `QD_FACTOR_WINSOR_LOWER|UPPER|RANK_TIES|NAN_POLICY|ENABLE_ZSCORE|ZSCORE_DDOF`；非法枚举/范围抛 `ValueError`。
    - `winsorize_series(s, lower_q, upper_q)`：在当日非 NaN 子集计算分位（pandas 默认线性插值）后 `clip`，输出 index 保留且原 NaN 槽位保持 NaN。
    - `rank_series(s, method, pct)`：委托 `pandas.Series.rank`，默认 `pct=True` 输出 0~1 分位秩。
    - `zscore_series(s, ddof)`：在当日非 NaN 子集做截面 z-score，`std==0` 时结果为 NaN（避免 inf）。
    - `apply_nan_policy(s, policy)`：`drop|median_fill|zero_fill`；其中 `drop` 必须满足“参与计算时剔除、输出时按原 index 对齐回填 NaN”。
    `__init__.py` 仅导出本 phase 公共 API（config + normalize 符号）。
  </action>
